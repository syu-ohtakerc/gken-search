# 基礎問題(5問)

## 問1
多クラス分類で、クラス数がKのとき、One-vs-One方式で必要な二値分類器の数はどれか。
1. K
2. K−1
3. K(K−1)/2
4. K²

**正解:3**
解説:全クラスの組み合わせ数 C(K,2)=K(K−1)/2。
不正解:1=One-vs-Rest。2=根拠なし。4=組み合わせ数ではない。

## 問2
アンサンブル学習のうち、弱学習器を逐次的に学習し、前のモデルの誤りを次のモデルで補う手法はどれか。
1. バギング
2. ブースティング
3. ランダムフォレスト
4. k近傍法

**正解:2**
解説:ブースティングは逐次学習でバイアスを減らす。
不正解:1,3=並列でバリアンス低減。4=アンサンブルではない単体手法。

## 問3
主成分分析(PCA)の説明として最も適切なものはどれか。
1. 正解ラベルを用いてクラス間の分離を最大にする
2. 非線形な写像で局所構造を保つ
3. 文書を単語の出現頻度で表現する
4. ラベルを用いずにデータの分散が最大になる方向を求める

**正解:4**
不正解:1=LDA。2=t-SNE/UMAP。3=BoW。

## 問4
文書を単語の出現回数のベクトルで表し、語順を考慮しない手法はどれか。
1. Bag-of-Words
2. Skip-gram
3. LSTM
4. Transformer

**正解:1**
不正解:2=Word2Vecの学習方式。3,4=系列を扱い語順を考慮するモデル。

## 問5
階層的クラスタリングの結合過程を木構造で示した図はどれか。
1. 混同行列
2. ROC曲線
3. デンドログラム
4. 計算グラフ

**正解:3**
不正解:1=分類結果の集計表。2=分類性能の曲線。4=ニューラルネットの演算の流れ。

# 標準問題(10問)

## 問6
クラス不均衡が大きいデータの二値分類で、少数クラスの見逃しを特に減らしたい場合に重視すべき指標はどれか。
1. Accuracy
2. Recall
3. Precision
4. 決定係数R²

**正解:2**
解説:Recall=TP/(TP+FN)。見逃し(FN)が少ないほど高い。Accuracyは不均衡で誤解を招く。Precisionは誤検出(FP)の少なさ。R²は回帰指標。

## 問7
ランダムフォレストの特徴として適切なものはどれか。
1. 各決定木は逐次的に学習され、前の木の誤りを修正する
2. すべての木が同一の訓練データ全体・全特徴量で学習する
3. ブートストラップサンプルと特徴量のランダム選択で多様な木を作り、多数決する
4. 弱学習器の重みを誤分類サンプルに応じて更新する

**正解:3**
不正解:1,4=ブースティング。2=多様性がなく、アンサンブルの効果が出ない。

## 問8
Transformerのデコーダーにおいて、エンコーダーの出力を参照する層はどれか。
1. Source-Target Attention
2. マスク付きSelf-Attention
3. 位置エンコーディング
4. Layer Normalization

**正解:1**
不正解:2=デコーダー内の過去トークン参照(未来を隠す)。3=順序情報を付加。4=値の正規化。

## 問9
Attention(Q,K,V)=softmax(QKᵀ/√d_k)V について誤っているものはどれか。
1. Qは注目する側の問い合わせを表す
2. KとQの内積が類似度のスコアになる
3. √d_k で割るのは内積が大きくなりすぎるのを抑えるためである
4. Vはsoftmaxの重みを計算するために使われ、出力には使われない

**正解:4(誤り)**
解説:Vが重み付き和の対象で、出力そのもの。重みの計算に使うのはQとK。
不正解(正しい記述):1,2,3はいずれも正しい説明。

## 問10
学習が進むにつれ、過去の勾配の二乗の累積により実効学習率が単調に減少していく最適化手法はどれか。
1. Momentum
2. AdaGrad
3. Adam
4. SGD

**正解:2**
不正解:1=慣性。3=指数移動平均を使い、累積しない。4=学習率は固定(スケジュールがなければ)。

## 問11
Adamの説明として最も適切なものはどれか。
1. 勾配の1次モーメントと2次モーメントの指数移動平均を利用する
2. 学習率を自動で0にする
3. 勾配の二乗を単調に累積する
4. 勾配の符号のみを使う

**正解:1**
不正解:2=そのような性質はない。3=AdaGrad。4=別手法(Rprop系/signSGD)。

## 問12
自然言語処理の説明として誤っているものはどれか。
1. TF-IDFは多くの文書に出現する語の重みを小さくする
2. Skip-gramは中心語から周辺語を予測する
3. Word2Vecは文脈に応じて同じ単語に異なるベクトルを割り当てる
4. FastTextは文字N-gramを用いて未知語にも対応しやすい

**正解:3(誤り)**
解説:Word2Vecは単語ごとに固定ベクトル。文脈依存はELMo・BERT等。
不正解(正しい記述):1,2,4はいずれも正しい説明。

## 問13
LSTMに関する説明として適切なものはどれか。
1. ゲートは更新ゲートとリセットゲートの2つである
2. セル状態を持たない
3. 勾配消失・爆発を完全に解消する
4. セル状態と入力・忘却・出力の3つのゲートを持つ

**正解:4**
不正解:1,2=GRU。3=緩和するが完全ではない。

## 問14
CLIPの学習の説明として適切なものはどれか。
1. 画像のクラスラベルを用いた交差エントロピー最小化で学習する
2. 画像からテキストを一語ずつ生成する自己回帰モデルである
3. 画像とテキストのペアについて、正しいペアの類似度を高め、他のペアとの類似度を下げる対照学習を行う
4. テキストを用いず画像のみで学習する

**正解:3**
不正解:1=教師あり分類。2=キャプション生成モデル。4=画像-テキストが前提。

## 問15
k-means法と階層的クラスタリングの比較として適切なものはどれか。
1. 階層的クラスタリングはデンドログラムを切る位置でクラスタ数を決められる
2. k-meansはクラスタ数の事前指定が不要である
3. k-meansは常に同一の結果になる
4. 階層的クラスタリングは大規模データに最も向いている

**正解:1**
不正解:2=kが必要。3=初期値依存。4=計算量が大きく大規模には不向き。

# 応用問題(5問)

## 問16
商品の不正注文検知で、不正が全体の0.3%である。Accuracy 99.7%のモデルが報告された。最も適切な対応はどれか。
1. 十分高いのでそのまま運用する
2. 学習データから不正を全て削除する
3. 評価指標をAccuracyのまま、層化せずに分割する
4. 混同行列を確認し、Recall・Precision・F1・PR曲線などで評価し、必要ならクラス重みやサンプリングを検討する

**正解:4**
解説:常に「正常」と予測しても99.7%になるため、Accuracyは無意味な可能性。層化分割(クラス比率を保つ分割)も有効。
不正解:1=不正を見逃している恐れがある。2=不正を学習できない。3=Accuracyの問題が残り、評価用データに不正がほとんど入らない恐れもある。

## 問17
勾配ブースティング(GBDT)とランダムフォレストを比較した説明として適切なものはどれか。
1. どちらも木を並列に学習する
2. GBDTは残差(損失の負の勾配)を次の木で逐次的に学習し、バイアスの低減に寄与する
3. ランダムフォレストはGBDTよりも木を浅くして弱学習器にするのが一般的である
4. GBDTは外れ値・ノイズに全く影響されない

**正解:2**
不正解:1=GBDTは逐次。3=RFは通常深い木(バリアンスをバギングで下げる)。GBDTは浅い木。4=ノイズに敏感になりうる。

## 問18
英語から日本語へ翻訳するTransformerの推論時、デコーダーがすでに生成した「私は」の次を予測する場面での記述として適切なものはどれか。
1. マスク付きSelf-Attentionにより、生成済みトークンのみを参照し、Source-Target Attentionで原文のトークンを参照する
2. デコーダーはまだ生成していない後続のトークンも自由に参照できる
3. Source-Target Attentionでは、Qはエンコーダー出力から、K,Vはデコーダーから作られる
4. 位置エンコーディングは翻訳では不要である

**正解:1**
不正解:2=未来参照はマスクされる。3=逆(Qはデコーダー、K,Vはエンコーダー)。4=位置情報なしでは語順が失われる。

## 問19
次の記述のうち、PCAとt-SNEについて適切なものはどれか。
1. どちらも線形変換であり、新しいデータにも同じ変換を容易に適用できる
2. PCAは教師あり、t-SNEは教師なしである
3. t-SNEのクラスタ間距離は常にデータの真の距離を反映する
4. PCAは分散最大の線形軸を求め、t-SNEは高次元の近傍関係を低次元で保つ非線形可視化手法である

**正解:4**
不正解:1=t-SNEは非線形かつ新データへの適用が不得意。2=どちらも教師なし。3=大域的な距離は信頼しにくい。

## 問20
RNNを用いた長い時系列の学習で損失が突然NaNになった。原因と対策の組み合わせとして最も適切なものはどれか。
1. 勾配消失が原因であり、勾配クリッピングが有効
2. 勾配爆発が疑われ、勾配クリッピングや学習率の低下が有効
3. 過少適合が原因であり、ドロップアウトの強化が有効
4. 次元の呪いが原因であり、PCAの適用が唯一の解決策

**正解:2**
解説:NaNや損失の急上昇は勾配爆発の典型。クリッピング(勾配のノルムを上限で切る)、学習率低下、適切な初期化など(LSTM/GRUは主に勾配消失の緩和策で、爆発はクリッピングで抑えるのが基本)。
不正解:1=消失は学習停滞が典型でクリッピングは爆発対策。3=ドロップアウトは過学習対策。4=「唯一」は過度な一般化。
