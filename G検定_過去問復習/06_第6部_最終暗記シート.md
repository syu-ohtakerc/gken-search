# B. 一問一答の最終チェック(直前用)

- 不均衡データで避けるべき指標? → Accuracyだけで判断すること
- バギングが減らす誤差? → バリアンス
- ブースティングが減らす誤差? → バイアス
- ランダムフォレストはバギング?ブースティング? → バギング
- AdaGradの欠点? → 学習率が減り続ける
- Adamの標準値? → β1=0.9, β2=0.999
- PCAは教師あり? → いいえ(教師なし)
- BoWは語順を? → 考慮しない
- Word2Vecは文脈で変わる? → 変わらない
- Source-TargetのQは? → デコーダー側
- GRUのゲート数? → 2
- LSTMのゲート数? → 3
- CLIPはゼロショット分類が? → できる
- FIDは? → 小さいほど良い
- k-meansはkの指定が? → 必要
- ドロップアウトの目的? → 過学習抑制

# D. 総復習確認問題(各テーマ1問・計10問)

1. OvRの分類器数と、OvOの分類器数を、クラス数Kで答えよ。→ K / K(K−1)/2
2. 「バギングは主に( A )を減らし、ブースティングは主に( B )を減らす」→ A=バリアンス、B=バイアス
3. Source-Target AttentionでQ,K,Vはどこから来るか。→ Q=デコーダー、K,V=エンコーダー出力
4. AdaGradの欠点と、それを改善した手法を2つ挙げよ。→ 学習率が減り続ける/RMSprop、AdaDelta
5. PCAとLDAの最大の違いは。→ ラベルを使うか(PCAは使わない、LDAは使う)
6. 「犬が猫を噛む」と「猫が犬を噛む」でBoWは同じベクトルか。→ 同じ(語順無視)
7. 階層的クラスタリングの結果を表す図と、クラスタ数を決める方法は。→ デンドログラム、切る高さ
8. CLIPがゼロショット分類を行う手順を述べよ。→ クラス名をテキスト化→埋め込み→画像埋め込みとの類似度が最大のクラスを選ぶ
9. LSTMのゲート3つとGRUのゲート2つを挙げよ。→ 入力・忘却・出力 / 更新・リセット
10. 勾配爆発の主な対策は。→ 勾配クリッピング(補助的に学習率を下げる、適切な初期化)
